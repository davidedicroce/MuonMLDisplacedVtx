Summer Student Project CERN / ATLAS Muon Spectrometer ML
Project Overview

GNNs for Displaced Vertex Classification

The project studies graph neural networks for identifying displaced vertices in the ATLAS muon spectrometer using event graphs built from muon segments and calorimeter towers.

Current Pipeline

  • Convert ROOT files into HDF5 graph datasets.
  • Build nodes from muon segments and calorimeter towers.
  • Connect segment-tower pairs using geometric proximity and edge features.
  • Train graph-level binary classifiers for signal versus background.

My Focus

  • Run Optuna tuning for the GAT residual architecture.
  • Compare GAT behavior against the edge residual baseline.
  • Study GAT-specific improvements such as attention heads, dropout, pooling, and edge-aware attention.
